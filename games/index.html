Quick guide

How to use your library

Get the shared library

On your first visit the library starts as a copy of the shared library. When a newer shared library is published, a notice appears at the top of the page; choose Review update to see how many games are new, changed or removed. You can also choose Get shared update in Manage library at any time. Accepting replaces this browser's library, so export a backup first if you need to keep local additions or changes.

Add or update a game

Select Add game, enter a title, fill in any details you want, choose a status, then save. Duplicate titles and duplicate Steam app IDs are blocked; edit the existing entry instead. Select the pencil button on a card to edit it later. High priority marks a game with a star.

Add a Steam link

Paste a Steam Store page URL into Steam URL, for example https://store.steampowered.com/app/123456/Example_Game/. It will appear as a link on the card. Fetch Steam info fills in public details, and Fetch trailers loads the trailers Steam lists for that game. Choose a trailer to save it to the game. Steam lookup works on the published site through its proxy, not when this page is opened as file://.

Watch a trailer

The play button on a game's cover opens its trailer in an in-page player. Steam HLS trailers use HLS.js where needed; YouTube links and direct HTTPS MP4/WebM URLs are also supported. Click the backdrop or close button to stop playback.

Add a cover picture

Paste a direct image URL into Cover image URL, such as an image address ending in .jpg or .png. The browser needs access to that image host to show it.

Organize and find games

Enter tags separated by commas. Use Start, Mark played, or Replay to move a game between statuses. Search and filters can be combined with each library view. Active filters appear as removable chips below the toolbar. More details on a card shows the full description, Steam categories and personal notes.

Choose what to play and how it looks

Use the sort menu to order the current list by title, priority, or random order. Pick a game makes a random suggestion from the current view and filters; choose Suggest another or start it. Open Manage library to change appearance or access sharing and backup actions. The appearance choice is saved in this browser.

Share or back up

Markdown for Discord lets you choose game groups and details, then copy or download the result. Export library downloads a JSON backup; importing one replaces the current library after confirmation. Browser site data is local to this browser and device, so keep regular backups.

The site owner can choose Publish to GitHub to make this browser's library the shared library for everyone. It needs a GitHub access token with write access to the site's repository.

Share with everyone

Publish to GitHub

Saves this browser's library as the shared library on GitHub. The site updates within a couple of minutes, and everyone else gets an update available notice.

Use a fine-grained token with access to only the antonlovg.github.io repository and Contents: Read and write permission. The token is sent only to GitHub.

Everything in the library, including personal notes, becomes public.
