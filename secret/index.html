QUICK GUIDE

How to use your library

Add or update a game

Select Add game, enter a title, fill in any details you want, choose a status, then save. Select Edit on a card to change it later. The ! checkbox marks a high-priority game.

Add a Steam link

Paste a Steam Store page URL into Steam URL, for example https://store.steampowered.com/app/123456/Example_Game/. It will appear as a link on the card. Fetch Steam info fills in public details, and Fetch trailers loads the trailers Steam lists for that game. Choose a trailer to save it to the game. Steam lookup works on the published site through its proxy, not when this page is opened as file://.

Watch a trailer

The Trailer button opens the saved trailer in an in-page player. Steam HLS trailers use HLS.js where needed; YouTube links and direct HTTPS MP4/WebM URLs are also supported. Click the backdrop or close button to stop playback. Steam lookup requires a valid Steam app URL and the deployed lookup proxy.

Add a cover picture

Paste a direct image URL into Cover image URL, such as an image address ending in .jpg or .png. The browser needs access to that image host to show it.

Organize and find games

Enter tags separated by commas. Use Start, Mark played, or Replay to move a game between statuses. Search and filters can be combined with each library view. Active filters appear as removable chips below the toolbar.

Choose what to play and how it looks

Use the sort menu to order the current list by title, priority, or random order. Pick a game makes a random suggestion from the current view and filters; choose Suggest another or start it. Open Library tools to change appearance or access sharing and backup actions. The appearance choice is saved in this browser.

Share or back up

Markdown for Discord lets you choose game groups and details, then copy or download the result. Export library downloads a JSON backup; importing one replaces the current library after confirmation. Browser site data is local to this browser and device, so keep regular backups.
